# スロ探究の編集作業

リポジトリ最上位のAGENTS.md・SECURITY.mdの安全要件に加えて適用する。

- 着手前に README.md、editorial/README.md、editorial/DECISIONS.md、editorial/WORKLOG.md を読み、既存の決定・今回の対象・未解決事項を確認する。
- 公式情報は editorial/official-source-checklist.md の順で探索する。記事の各主張と出典本文を照合する。
- 新規記事・重要な事実の更新では、原稿作成とは別の実行担当による独立検証を必須とする。役割名だけの自己点検を独立検証としない。
- 修正理由を共通ルールと今回だけの判断に分けて記録する。決定記録に反する表現を次の原稿に再導入しない。
- 作業後は WORKLOG.md に変更、検証結果、未実施、承認・公開状況と次の行動を記録する。未実施を合格にしない。
- 今回の承認範囲を確認する。過去記事の公開承認を、新しい記事修正の公開承認として流用しない。
