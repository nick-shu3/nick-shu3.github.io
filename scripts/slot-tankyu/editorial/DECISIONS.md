## 繰り返し適用するルール

| ID | 指摘・理由 | 共通ルール | 確認する場所 |
|---|---|---|---|
| E01 | 出典一覧だけでは主張の確認状況が追えない | 主張ID・原稿箇所・URL・確認箇所・確認日・状態・担当者を必須にする | 根拠表 |
| E02 | 条件付き確認の注記が本文にない | 制限を本文・タイトル・表・画像説明の該当箇所に明示し、誤認しないか検証する | 全表示箇所 |
| E03 | 数字と日付だけでは仕様の誤りを見逃す | 重要仕様・メーカー発言・ゲーム性も確認対象 | 全主張 |
| E04 | 掲載日と出来事の日付の混同 | 発表会実施／記事掲載、全国導入／店舗別、収録／放送を別に記録 | 日付欄・本文 |
| E05 | 情報の取得失敗を未発表と誤解 | 取得不可・記載なし・未確認を区別。過去の読了を今回の読了としない | 探索ログ |
| E06 | 報道をメーカー公式発言のように扱う | 公式・二次報道・本人申告・考察を区別。リポスト・転載も区別 | タイトル・本文・出典区分 |
| E07 | 検証役の指定だけで独立検証と称する | 別実行の担当が元資料を照合し、担当・対象版・範囲を記録する。必須・未実施なら昇格禁止 | 独立検証記録 |
| E08 | 修正後に旧版の合格を流用 | 原稿のSHA-256と根拠表・検証記録を照合し、変更後は再検証 | 対象版 |
| E09 | 試行中・作業状況が読者向け本文に入る | 制作状況は編集記録へ。本文は読者が知りたい事実・意味を先に書く | 公開原稿 |
| E10 | 合格と未実施が混ざる | 内容・安全・生成・表示・公開を別に判定。未実施を合格にしない | 検査記録・最終報告 |
| E11 | 同じ指摘が毎回必要 | 作業開始時にこの記録を読む。新しい修正理由は共通／案件固有に分けて追加 | AGENTS.md・引き継ぎ |
| E12 | 平均と中央値、実績と意向の混同 | 集計対象・統計量・比較期間を明記し、異なる集計を直接優劣比較しない | 数値本文・見出し・表 |
| E13 | イベント内の個別企画の日時を流用 | 開催期間、企画日、試打日を別に確認し、一つの企画日を別企画に転記しない | イベント記事 |

## 継続するサイトの条件

- 新台・ニュースの新規調査対象はパチスロ。パチンコ新機種を追加しない。統計等の既存パチンコ比較を扱う場合も、記事の中心をパチスロに置く。
- 実戦記事は機種別。複数機種の合計は当日まとめのみ。
- 読者向けの日付は不要なゼロを除く。ISOのデータ・datetime属性は維持。「日時は日本時間」の注記は不要。
- 画像は既存のサイズ・EXIF・判読性ルールに従う。他社画像や記事全文を転載しない。
- 費用0円、公開は今回分の承認後。月曜の定期調査設定は今回変更しない。
