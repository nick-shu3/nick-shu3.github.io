遊び方・ダメージの仕組み

勇者は自動で進み、接触した魔物と交互に攻撃します。勇者が先制し、倒しきれなかったときだけ反撃されます。

与ダメージ＝攻撃力。被ダメージ＝魔物の攻撃力−防御力（最低1）。2体倒すごとにレベルが上がり、最大HP・攻撃力・防御力が成長します。

HPが尽きると3秒後に再出発。装備と最長記録を引き継ぎます。1,000mのゴールを目指してください。
