01 実戦データを入力

ゲーム数はボーナス中を除いた通常時の数。同じ開始・終了時点のデータを使ってください。

ON：通常時チェリー狙い、ベル・ピエロ全こぼし、ボーナスを1BETで揃える、ブドウ抜きあり。

OFF：通常時適当押し、ボーナスを1BETで揃える、ブドウ抜きなし。

単にチェリーを数えたかどうかの切替ではありません。混在した打ち方や、ホール全体のデータで打ち方が不明な場合は、両条件を参考として比較してください。完全な補正はできません。

逆算式・計算上の注意

G＝通常ゲーム数、B＝BIG、R＝REG、D＝差枚。

推定ブドウ回数＝
(D＋3G－251.25B－95.25R－0.411G－cG)÷8

c はOFF：0.040475、ON：0.06068。推定確率はG÷推定回数です。係数は提供された計算ファイルに準拠。251.25・95.25は計算上のボーナス補正係数であり、公表獲得枚数ではありません。0.411とcは小役等の平均収支を補正する係数です。ファイルには各係数の詳細な内訳やブドウ抜きの独立した補正項がないため、その内訳は断定せず、追加補正もしません。

小役の回数、取りこぼし、揃えるまでの手順、データ機器のゲーム数の数え方、差枚グラフの読み取り誤差で結果が変わります。途中の持ちメダルではなく、同一区間の差枚を使ってください。ボーナス中や成立したままのデータは対象外です。

推定回数は小数のまま計算し、画面では小数1桁。発生確率は二項分布を直接集計し、「以上」は切り上げ、「以下」は切り捨てた回数を境界にします。シミュレーションのゲーム数と関係なく、発生確率は実戦ゲーム数で計算します。

ゲーム数の上限100,000Gはブラウザの負荷を抑える本ツールの制限です。入力データは保存・外部送信しません。出典リンクは押した場合に外部サイトへ移動します。
