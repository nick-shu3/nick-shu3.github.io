SAO2｜設定推測・終了画面・やめどきガイド

SAO2の設定推測・終了画面・やめどきに加え、通常A〜D・天国、GGO、終了ボイス、通常時とAT中の高確を区別して確認。数値の分母と例外条件もまとめています。

設定推測・やめどき・狙い目最終更新：2026年10月17日

まず確認すること

実戦中は、画面と当選契機を記録

ATが終わったら、終了画面を確認してPUSH。画面は設定示唆、ボイスとランプはモード示唆として分けて記録します。エンディングやマザーズ・ロザリオ中は、レア役時のミニキャラも確認しましょう。

通常時は、CZ・ATが「何から当たったか」を残します。初当たりの回数に加え、CZ開始時からTHE ENDだったか、CZを経由せずATへ当たったかを記録すると、設定差のある当選と別の恩恵を分けて振り返れます。

やめる前は、区間と短縮対象を確認

AT終了後は50Gの引き戻し区間を確認する、というのが媒体の目安です。50Gを過ぎれば一律にやめてよい、という意味ではありません。前兆、メニューの示唆、所持アイテム、バレットカウンター、近いゾーンも確認します。

初回の上位CZ「デス・ガンバトル」失敗後は、CZ間の実ゲーム数天井が256G＋αへ短縮。ただし、上位AT経由の上位CZ失敗は対象外です。上位CZがどの経路で来たかを確認し、すべての失敗後に同じ短縮を当てはめないでください。

AT当選だけで通常Aへ戻るわけではない

初期モードは設定変更時・有利区間移行時に決まり、天国へ移行するまでは転落しないとされています。CZ失敗時は昇格と天国移行を抽選。AT終了時は昇格に加え、液晶天井を350Gにする抽選があります。

高確：通常時とAT中では抽選対象が違う

通常時の高確は、チャージ・CZ抽選を優遇

やめる前：引き戻しと短縮条件を確認

AT終了後は50Gの引き戻し区間を確認する、というのが媒体の目安です。50Gを過ぎれば一律にやめてよい、という意味ではありません。前兆、メニューの示唆、所持アイテム、バレットカウンター、近いゾーンも確認します。

初回の上位CZ「デス・ガンバトル」失敗後は、CZ間の実ゲーム数天井が256G＋αへ短縮。ただし、上位AT経由の上位CZ失敗は対象外です。上位CZがどの経路で来たかを確認し、すべての失敗後に同じ短縮を当てはめないでください。

  1. AT終了画面を記録し、PUSHボイス・左側ランプを確認する。
  2. 引き戻し区間を確認する。なな徹では下パネルの明滅が目印とされ、50G目のレア役成立は引き戻し濃厚とされる。
  3. メニューで実ゲーム数・液晶ゲーム数、モード示唆・アイテムを確認する。
  4. 前兆中・Sterbenステージ中ではないか、天井短縮の対象ではないかを確かめる。

上位AT終了後は状態別の検討が必要です。GGOの示唆や近いゾーン、引き戻し時の状態などが絡むため、通常AT後の目安をそのまま一律に適用しません。

AT引き戻し：方向性は断定しない

なな徹には高設定優遇の模様という記載がありますが、スロマガの実戦では設定1・5・6がそれぞれ4/22回・6/39回・3/50回でした。50G目の自力引き戻しを除外した少数の観測です。この結果から低設定優遇とも、高設定優遇とも断定しません。通常の初当たりとは別に、試行回数と50G目の成立役を記録する参考項目です。
