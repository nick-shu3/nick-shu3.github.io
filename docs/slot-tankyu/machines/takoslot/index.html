ユニメモで、出玉と技術介入の成績を見る

「当たりは軽かったか」「14枚を何回取れたか」。ユニメモでは、ボーナス結果と技術介入の成績を別々に振り返れます。このページでは、数字を見るときの分母と記録のポイントを説明します。

記録するときの確認事項

  • 総プレイ数と通常時プレイ数を分け、表示確率の分母を確認する。
  • BIG・REG、白7BIG・タコBIGを分けて残す。
  • タコゲーム回数、共通役、14枚取得・9枚取得の回数を記録する。
  • 収支と技術介入の結果を分け、短い実戦だけで設定を断定しない。

本人の記録方法を整理したものです。機種仕様・技術介入手順を確定する攻略情報ではありません。
