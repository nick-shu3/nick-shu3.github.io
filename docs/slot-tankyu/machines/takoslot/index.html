設定推測とユニメモ記録の要点

スマスロ タコスロはユニバーサルブロスのBT機。設定は1・2・5・6の4段階です。ボーナス・通常時小役・BT中の抽選・BB終了画面を分けて記録し、短い実戦だけで設定を断定しないようにしましょう。

ボーナスと通常時小役は通常時G、リプレイ＋TACO GAMEはBONUS GAME（BT）中のGが分母です。総プレイ数や14枚取得率と混ぜないでください。

BT中のリプレイ＋TACO GAME

分母はBONUS GAME（BT）中の消化G数。通常時Gや、リプレイ成立回数で割る確率ではありません。

確認手順は中・右を止め、リプレイがテンパイしたら、左枠上に鉢巻付き白7をビタ押し。上段白7停止が成功形です。そのときタコランプが点灯すれば、一撃では同時当選濃厚!?としています。

成立した当該Gで手順を成功させた場合だけ有効です。当該Gで失敗し、次のリプレイで成功させても点灯しません。手順失敗・未確認を非当選として数えず、成功回数・失敗回数も別に記録してください。検出漏れがある実測頻度は、上表と同条件では比較できません。

一撃・擬似リプレイハズシの手順と注意。スロマガは成功時の同時成立を「確定」と表記していますが、ここでは一撃の確度表現を保持します。

BB終了画面：夕方・夜と入賞条件

BB終了時に背景と、そのBBでのTACO GAME入賞有無を一緒に残します。「夜」だけと、入賞なしでの「夜」は分けてください。

夜の出現率は高設定ほど高いとされています。具体的な設定別出現率は今回の参照箇所では未確認です。14枚取得の成否と、TACO GAMEへの入賞有無は別条件。夜だけで設定5・6とは判断できません。

一撃・BB終了画面、パチマガスロマガFREE・BB終了画面。両媒体の確度表記の違いを残しており、メーカー公式の確定示唆とは扱いません。

記録するときの確認事項

  • 総プレイ数と通常時プレイ数を分け、表示確率の分母を確認する。
  • BIG・REG、白7BIG・タコBIGを分けて残す。
  • タコゲーム回数、共通役、14枚取得・9枚取得の回数を記録する。
  • 収支と技術介入の結果を分け、短い実戦だけで設定を断定しない。

この節は本人の記録方法の整理です。目押し手順と設定推測の公表解析は上の各節で区別しています。
