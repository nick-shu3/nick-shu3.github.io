S｜設定確定・否定演出

設定確定・否定パターンは示唆より優先。演出ごとに対象設定・出現場面を区別。出典の個別確認が済むまで画像一覧は掲載保留。

S｜トロフィー・獲得枚数

銅2以上、銀3以上、金4以上、特殊(喰)5以上、虹6。黒は次回トロフィー出現予告で、黒単体で設定を確定しない。456OVERは4以上、666OVER・1000-7OVERは6の示唆とされる。

A｜AT初当り確率

通常時ゲーム数とAT初当り回数を記録。短時間の偏りが大きいため他指標と総合判断。

A｜CZ合算・レミニセンス

CZ合算とレミニセンス単体を混同しない。上位CZ「大喰いの利世」も分離して記録。

A｜大喰いの利世（上位CZ）

上位CZの出現頻度には設定差。レミニセンスと混ぜず別カウント。

A｜100G以内CZ当選率

100G以内CZ当選率には設定差。朝一モード・設定変更後などの条件を混ぜず、解析値と同じ集計条件を確認。

B｜エピソードボーナス

エピソードボーナスの出現率に設定差。通常のCZ当選とは別記録。

B｜リプレイ契機AT直撃

リプレイ契機のAT直撃には設定差。ゲーム数天井・CZ経由などと区別。

B｜AT引き戻し

AT終了後の引き戻しは設定差。引き戻し判定対象と回数を揃えて記録。

B｜裏AT突入率

AT初当り時の裏AT突入率に設定差。規定ゲーム数契機など別条件の抽選と混同しない。

B｜高確移行・状態別CZ抽選

「高確への移行率」と「高確滞在時のCZ当選率」は別項目。前者の全設定別移行率は今回裏付け不足で数値未掲載。弱チェリー契機のCZ当選率は通常・高確・超高確で区別する。

高確への移行率と、超高確中のレア小役によるCZ当選率は別の母数です。後者の設定1→6は弱チェリー40.3%→64.4%、スイカ13.7%→22.0%（二次資料）。

B｜精神世界30G選択率

精神世界の継続30G選択率には設定差があるとされ、設定1対6で約4倍。内部状態と見た目のステージが一致しない場合があるため実戦での判定に注意。

30G表示の選択率は設定1・2が3.13%、設定6が12.50%（二次資料）。表示30Gと内部保証33Gを区別します。

B｜有馬乱入選択率

ATセット数による有馬乱入選択率。設定1のセット数別振り分けが公開されているが、高設定の全設定別数値は未確認。単純な乱入回数ではなくセット数を併記。裏AT中は別扱い。

有馬乱入はATセット数・裏ATか否かによって条件が異なります。設定別の完全な比較表は未確認のため数値で高低を断定しません。

C｜下段リプレイ確率

下段リプレイに小さな設定差。十分な試行回数が必要な補助要素。

S｜終了画面・CZカード・招待状

AT/CZ終了画面、エンドカード、月山招待状、エンディングカードを別々に整理。設定示唆とモード・前兆示唆を混同しない。

C｜弱チェリー等のCZ抽選

弱チェリーの状態別CZ抽選、精神世界中の弱チェリー・スイカ抽選を確認。状態推定が曖昧な場合は設定推測に直接使用しない。
