4thシーズン開幕！ RED第1回戦

ついに777リーグ4thシーズンが開幕。キコーナサンクスのホーム戦に、嵐さん、寺井一択さん、スロミック・エイキさん、ゆうちゃろさんが出場しました。

それぞれの実戦と開幕戦の印象を、シュウ３の視聴メモをもとに振り返ります。

動画前後編と出場者は公式アカウントの告知を検索表示経由で確認。順位、実戦機種と展開はシュウ３提供の視聴メモに基づきます。動画本編の音声・映像の直接照合はできていません。

出場選手

  • 嵐：キコーナサンクス
  • 寺井一択：123エンターテイナーズ
  • スロミック・エイキ：テンガイゴールデンメインズ
  • ゆうちゃろ：マルハンフォースエナジー

実戦結果・順位

ここからは視聴メモに基づく結果を記載します。ネタバレにご注意ください。

  1. 寺井一択（123エンターテイナーズ）
  2. 嵐（キコーナサンクス）
  3. スロミック・エイキ（テンガイゴールデンメインズ）
  4. ゆうちゃろ（マルハンフォースエナジー）

寺井さんは真打 吉宗で苦しい序盤から巻き返し。嵐さんはゴーゴージャグラー3を打ち切り、エイキさんも台移動を経てプラス収支へ。ゆうちゃろさんは東京喰種（999）で見せ場を作るものの、厳しい結果となりました。

シュウ３のコメント

ついに777リーグ4thシーズンが始まりました。チェックしていきたいと思います。

冒頭をかき乱すのは、さすがのゆうちゃろさん。波乱を起こすのが目的とのことで、それはばっちりとハマっているように見えます。

スロミック・エイキさんは緊張が伝わってきます。どんな活躍をされるか楽しみです。

ゆうちゃろさんと出番が被った寺井一択さんは、やや霞むような気がします。相手が相手だから、そして、777リーグの緊張感からかと思われます。

そして、不死鳥のように復活したキコーナサンクスより嵐さん。並々ならぬ気合いとともに初戦からホームで登場です。

それでは最終結果も書いていきましょう。

初戦で真打 吉宗を打つのもすごいが、投資がかさんでから今日初の真高確率で青7を射止めるのは素晴らしい。そしてループもさせて。ミスター777リーグという呼称も大げさではない？ お見事でした。1位おめでとうございます。

2位はゴーゴージャグラーを打ち切った嵐さん。2ndシーズンでは初戦に大きなマイナスを背負っていただけに、今回のプラス収支と2位獲得は相当に嬉しそうでした。

3位は緊張感が半端じゃなかったスロミック・エイキさん。後半にようやく少し落ち着いたようで、同じくゴーゴージャグラーでプラス収支へ。この戦いを生かした今後の戦いに期待です。

最下位となってしまったのは、東京喰種で連チャンを射止められなかったゆうちゃろさん。いつか出玉を大爆発させることを期待しています！
