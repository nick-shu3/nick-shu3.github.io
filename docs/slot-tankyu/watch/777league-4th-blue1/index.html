BLUEリーグの開幕戦

宮崎県のSuper D’station大淀店を舞台に、4選手がそれぞれの戦い方で挑みます。シュウ３の視聴メモと感想をもとに、BLUE第1回戦を振り返ります。

会場・選手は公式告知の検索表示で確認。順位、機種、実戦経過などはシュウ３提供の視聴メモに基づきます。動画本編の音声・映像は直接照合できていません。

出場選手

  • 日直島田：D’ステーションヒーローズ
  • 橘リノ：フェイスメガタイガース
  • 司芭扶：ガーデンユナイテッド
  • コウタロー：アルマダイナム

視聴メモによると、朝の抽選には1,300人を超える参加者が集まりました。

実戦結果・順位

ここからは視聴メモに基づく結果です。ネタバレにご注意ください。

  1. コウタロー（アルマダイナム）
  2. 橘リノ（フェイスメガタイガース）
  3. 司芭扶（ガーデンユナイテッド）
  4. 日直島田（D’ステーションヒーローズ）

4選手全員がマイナス収支という厳しい展開の中、ジャグラーで粘ったコウタローさんがトップに。橘リノさんは牙狼での挑戦を経て、終盤に大海物語5 ブラック LT99へ移動。司芭扶さんも苦戦し、日直島田さんは朝イチ4回転で大当りを引いた後、次の大当りを引けず深いハマりに苦しみました。

シュウ３のコメント

派手な出玉には恵まれなかったものの、少し展開が違えば結果は大きく変わっていたかもしれません。惜しかったぞ、みんな！

1位：コウタローさん――ハッピージャグラーで粘る

ウルトラミラクルジャグラーから実戦をスタートし、その後ハッピージャグラーV IIIへ移動したコウタローさん。

REGが先行する一方で、なかなかBIGがついてこない展開でした。それでも大崩れを避けながら粘り続け、見事に初戦トップを獲得！

打っていたハッピージャグラーは、設定も悪くなさそうに見えただけに、マイナスでのフィニッシュは少し残念。次回以降は、台の良さに見合った結果がついてくることを期待したいですね。

2位：橘リノさん――牙狼へのリベンジ、あと一歩

橘リノさんは、前シーズンに苦い思いをした牙狼へ再び挑戦。その姿勢はさすがです！

ラッキートリガーへのチャレンジは2回とも突破できず、「あと50％を突破できれば……」という悔しい展開に。終盤は大海物語5 ブラック LT99へ移動し、連チャンで出玉を確保しました。

今回は惜しいところで届きませんでしたが、次こそは怒涛のような展開を見せてほしいです。

それにしても、マスクをしていない橘リノさんを見るのはいつ以来だろう？ 普段はマスク姿の印象が強かったので、久しぶりに素顔を拝見しました。美人っすね。

あと、リーダーのsasukeさんのことも気になっています。チームの今後も含めて、応援していきたいところです。

3位：司芭扶さん――今回は苦戦も、逆襲に期待

狙いのスロットを確保できず、パチンコの『P引きこもりでも恋がしたい！』で実戦した司芭扶さん。

初当りやチャンスまでの道のりが重く、今回はなかなか見せ場を作れない厳しい展開でした。残念でしたが、まだまだ初戦。このまま終わるとは思えないので、次戦以降の逆襲に期待しています！

4位：日直島田さん――朝イチ4回転から、まさかの展開

日直島田さんは『PF.機動戦士ガンダムSEED』で、なんと朝イチ4回転で大当り！

これは初戦からとんでもないことをやらかすのでは……と思ったら、別の意味でやらかしていました。通常当りの後は次の大当りを引けず、約1,400回転のハマり。マジか……パチンコ、怖い。

状況は良さそうに見えただけに、島田さんも展開に苦しんだ印象です。パチンコにスポットライトを当てているのは良いと思うので、次こそは出玉も伴う実戦を見せてほしい！

島田さん、なんとかしてください！

BLUE第1回戦は、全員マイナスという苦しいスタートになりました。

ただ、牙狼のチャレンジを突破していたら、ジャグラーのBIGがもう少しついてきていたら、島田さんが早い段階で次の大当りを引けていたら……。少しの違いでまったく別の結果になっていたかもしれません。

まだリーグは始まったばかり。4選手、そして各チームの次の戦いにも注目です！
