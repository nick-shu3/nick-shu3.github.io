新台解説

LB海スロ発表｜BB平均約450枚は何を含む？ 公式資料で読むBTの仕組み

LB海スロは2027年2月8日がトップ導入予定。BB約300枚、BTループ約50％、BB平均約450枚の関係を、11月6日付のメーカー発表から整理します。

まず押さえたいポイント約300枚と平均約450枚の違い選べる4つのモード導入予定と今後の確認点確認元・関連記事

まず押さえたいポイント

三洋販売とサンスリーは11月6日、パチスロ新機種「LB海スロ」を発表しました。メーカーはサンスリー。トップ導入日は2027年2月8日（月）の予定です。

注目は、BBから必ずボーナストリガー（BT）へ進む仕組み。メーカー発表の「BB平均獲得枚数約450枚」は、BBだけで一度に受け取る枚数とは分けて読む必要があります。

情報確認日：2026年11月7日。以下は発売前のメーカー発表に基づく解説で、実戦での獲得枚数を測定したものではありません。

約300枚と平均約450枚の違い

発表資料では、BBの約150枚とBTでの約150枚を合わせて約300枚。その後は約50％でBTがループし、ループするたびに約150枚を上乗せすると説明されています。

11月6日付メーカー発表の数値
項目案内された数値・意味
BB獲得枚数約300枚。BB約150枚＋BT約150枚
BTループ率約50％
BT上乗せ枚数ループするたびに約150枚
BB平均獲得枚数BTのループを含めて約450枚
RB獲得枚数約88枚

つまり、約300枚と平均約450枚は別の機種性能を比べた数字ではありません。同じBBについて、最初のBT分までの枚数と、さらにループする分を含む平均を分けた説明です。

平均約450枚は毎回の獲得を保証する数字ではなく、投資を差し引いた差枚でもありません。約50％というループ率から「2回に1回は必ず続く」とも判断できません。

選べる4つのモード

通常時は「完全告知」「魚群」「もっと魚群」「アクティブ」の4モードを搭載。メーカーは、告知ランプでボーナスを知らせるゲーム性を案内しています。

BTループはBB消化中や終了時の「ビッグバイブ」で報知すると説明されています。BBに当選したことと、その後のBTループがどこまで続くかは、分けて見ておきたいところです。

導入予定と今後の確認点

2027年2月8日はメーカーが案内したトップ導入予定日です。すべての店舗で同日に打てるという意味ではないため、実際に行く店舗の新台入替案内を確認してください。

今回確認した発表資料だけで、設定推測の精度や実際の遊びやすさまでは評価できません。初打ちを考える際は、平均獲得枚数だけで収支を見積もらず、ボーナスまでの投資とBTの終了を分けて記録したいところです。
