2026年11月3日、メッセ吉祥寺の周年日に実戦してきました。

私が打ったのは、ゴーゴージャグラー3の697番台。投資184枚、回収1,976枚、差枚＋1,792枚で終了しました。

何とか勝つことはできましたが、自分の台だけを見ていても、お店全体の設定状況は分かりません。

そこで今回は、ジャグラー9機種・計128台のデータを集計。「周年日の当たり機種はどこだったのか」を振り返ってみます。

先に私の印象を言うと、少数台ではジャグラーガールズSS、台数のある機種ではゴーゴージャグラー3が気になる結果でした。

少数台で気になったのはガールズSS

今回、最もまとまりを感じたのがジャグラーガールズSSです。

全5台で41,516G。BIG173回、REG152回でした。

  • BIG確率：1/240.0
  • REG確率：1/273.1
  • 合算確率：1/127.7

メーカーの設定5参考値はBIG1/243.6、REG1/270.8、合算1/128.3。機種全体の結果は、この数値に近い組み合わせです。メーカーは工場データから算出した予測値としています。

特に気になったのは次の3台でした。

一台だけが大きく当たって平均を引き上げた形ではなく、複数台で良好な合算が見られたのが印象的でした。ただし、741番の合算は1/143.4など、台ごとにばらつきがあります。

もちろん、これだけで「全台設定5以上」とは言えません。740・743番はBIGが先行しており、全台を同じ強さで評価するのも慎重にしたいところです。

それでも、機種単位の仕掛けを考えるなら、今回の有力候補はガールズSSだと思います。

ゴージャグ3は16台の中に好結果が広がる

私が実戦したゴーゴージャグラー3も、機種全体で見ると悪くありません。

全16台で126,143G。BIG489回、REG454回です。

  • BIG確率：1/258.0
  • REG確率：1/277.8
  • 合算確率：1/133.8

REGと合算は、メーカーの設定4参考値であるREG1/268.6、合算1/130.5に比較的近い結果でした。一方、BIGは高設定を強く推せる数値ではありません。

注目したいのは、16台中11台がREG1/300以内だったことです。特に次の台はREGが優秀でした。

また、687番はBIG47回・REG28回で合算1/104.1という派手な結果です。ただ、REGは1/278.9。BIGの当選回数が多い台と、REGが特に優秀な台が必ずしも一致しないところも、ジャグラーらしいですね。

私の697番台は、今回の店舗データではBIG36回・REG26回、REG1/305.2でした。周囲と比較すると、REGが特に強かった側ではありません。

勝てたことは嬉しいですが、「勝ったから自分の台が一番良かった」とは言えなさそうです。

ミスターも候補。ほかの機種は慎重に

ミスタージャグラーは3台合計で、BIG1/235.2、REG1/301.6、合算1/132.1でした。

中でも745番は8,261GでBIG42回・REG32回、合算1/111.6。十分に気になる結果です。

ただし、ほかの2台はREGがともに1/320台。3台という少数構成でもあり、機種全体の仕掛けとまで評価するには材料が足りません。

ネオアイムは、711番の7,761G・BIG29回・REG35回など、個別に良好な台がありました。一方、32台全体のREGは1/333.2。広く高設定が入っていたとまでは言いにくい結果です。

ファンキー2は738番が8,460GでBIG34回・REG34回と良好でしたが、機種全体のREGは1/368.7でした。

ハッピーとウルトラミラクルも、今回の集計では機種全体を当たりと判断できる材料は乏しく感じます。

全台系や半台系だったのか？

今回のデータから、私が考えているのは次のような状況です。

  • ガールズSS：機種単位の仕掛け候補
  • ゴージャグ3：複数台に高設定が使われた可能性
  • マイジャグラー：個別台を中心に注目
  • ミスター：745番を中心に気になる結果
  • その他：個別の好結果はあるが、機種全体の評価は慎重に

ガールズの全台系や、ゴージャグの半台系・並びといった可能性はあります。

ただし、好調台の割合は、そのまま高設定の投入割合ではありません。

低設定でも良い結果になることはありますし、高設定でもボーナスが付いてこないことはあります。今回の数値だけで、全台系・半台系・末尾などの法則を特定することはできませんでした。
